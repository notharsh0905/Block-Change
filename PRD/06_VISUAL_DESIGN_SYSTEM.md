# 6. VISUAL DESIGN SYSTEM

## 6.1 Design goal

A distinctive, original style: - soft 2.5D blocks, - rounded geometry, -
subtle highlights, - soft depth, - clean typography, - playful
micro-motion.

## 6.2 Color palette

Suggested logical game colors: - Coral: #FF7A7A - Mint: #73D99A - Sky:
#6FA8FF - Violet: #9B7BFF - Sunshine: #FFD45C - Aqua: #55D6D6

These are starting tokens, not final immutable values. Accessibility
testing may require changes.

## 6.3 App surfaces

Use design tokens: - background - surface - surfaceElevated - primary -
secondary - textPrimary - textSecondary - success - warning - error -
border - shadow.

Do not scatter raw color literals throughout widgets.

## 6.4 Typography

Use one primary font family with: - Display - Heading - Body - Caption -
Button

Avoid excessive font variety.

If a third-party font is used, confirm its commercial license.

## 6.5 Depth

2.5D effect may use: - subtle shadow, - highlight edge, - slight
gradient, - tiny scale response.

Avoid heavy skeuomorphism.

## 6.6 Dark mode

Dark theme should not simply invert colors.

Use: - dark neutral background, - elevated cards, - controlled
saturation, - accessible text, - special tiles still recognizable.

## 6.7 Buttons

Buttons have: - rounded shape, - depth/shadow, - press-down animation, -
optional haptic, - SFX.

Primary CTA should be visually obvious.

## 6.8 Visual consistency

Every screen must use shared: - spacing, - radius, - typography, - color
tokens, - button components, - dialog components.

Do not create one-off styling unless justified.
